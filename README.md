UI Automation for Pet Clinic application with Playwright
Prerequisite: Before running tests set environmental variables: Using powershell - $env:BASE_URL="http://localhost:8080/"
Install Node -version 18+ or newer version
run test with npm run UI_TEST         
To view test results with allure:  npm run allure:open    
use "npm install" to install all modules if not availabe "npm playwright install" to install all browsers needed incase browsers have no been install
